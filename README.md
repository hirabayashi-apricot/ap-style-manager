# AP Style Tag Manager

クラシックエディタ（TinyMCE）に、JSONで管理したスタイルとHTMLの雛形をボタンで入れられるようにするWordPressプラグイン。株式会社アプリコットデザイン製。

## 設定の置き場所（1.2.0〜）
読む順番は次のとおり。
1. 管理画面（設定 → スタイルタグ）で保存した内容（DBのオプション `apsm_style_formats`）
2. テーマの `apsm.json`（子テーマを優先）。書き方は `apsm.schema.json`
3. どちらも無ければ空

管理画面で保存すると、以後はそちらを優先する。設定画面の「テーマのファイルに戻す」でテーマの `apsm.json` に戻せる（直前の内容は1世代だけ `apsm_style_formats_bak` に控える）。

各項目の `description`（いつ使うか）は、エディタのボタンにマウスを乗せると出る。人とAIが使い分けを判断するための一文。

## チェック（WP-CLI）
```
wp apsm check
wp apsm check --class-pattern='^(c|u)-[a-z0-9]+(-[a-z0-9]+)*$'
```
- 各クラスが、テーマの表側のCSSと編集画面のCSS（`add_editor_style()` で登録したもの）の両方にあるかを確かめる
- `--class-pattern` を渡したときだけ、クラス名がその正規表現に合うかも確かめる（プラグインは特定の命名ルールを持たない）
- 1つでも × があれば失敗（終了コード1）

## 更新の配り方
- GitHubのリリースに添付したzipで配る（plugin-update-checker の GitHub モード）
- リリースの作り方: `Version:` を上げてコミット → `./build.sh` → タグ `v<版>` でリリースを作り、`dist/ap-style-manager-<版>.zip` を添付する
- 1.1.0以前は設定をプラグインのフォルダ内に保存していたため、そこから上げると設定が1回消える。上げる前に設定画面でエクスポートし、上げたあとにインポートする
